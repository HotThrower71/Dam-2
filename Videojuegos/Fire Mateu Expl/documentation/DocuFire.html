6. Dos hilos a la vez

  
Un hilo es un trabajador independiente. Hay dos: uno mueve el fuego y otro refresca la ventana. Cada punto es una vuelta de su bucle.

  

    
    

    

      
Model-Fire cada 33 ms · pasos: 0

      
fire-view cada 16 ms · refrescos: 0

      
Refrescos por cada paso del fuego: –

    

  

  
La ventana refresca el doble de rápido de lo que el fuego cambia, así que a veces repinta lo mismo. No pasa nada: ninguno espera al otro.







  
7. Qué pasa al dibujar

  
La vista no dibuja directamente. Sigue esta cadena:

  

    
viewer.setImage(img)
guarda la imagen
→
    
repaint()
avisa de que hay que redibujar
→
    
update(g)
Java lo llama cuando puede
→
    
paint(g)
dibuja la imagen estirada

  

  

    
✗ Sin sobrescribir update

      
El Canvas normal borra todo y luego dibuja. Eso se ve como un parpadeo.

      
borrar todo → dibujar imagen
borrar todo → dibujar imagen   ← parpadea

    
✓ Como está en Viewer.java

      
update solo llama a paint: no se borra nada y la imagen nueva se pone encima.

      
@Override
public void update(Graphics g){
    paint(g);
}

  

  
drawImage(...) estira la imagen para llenar el lienzo. Por eso el fuego crece si agrandas la ventana.







  
8. Glosario

  

    

      
Temperatura
Número de 0 (apagado) a 255 (lo más caliente). Cada punto tiene una.

      
Píxel
Un punto de la imagen. Hay uno por cada temperatura.

      
Tramo
El trozo entre dos colores clave (por ejemplo, de la temperatura 20 a la 80).

      
ratio
En qué punto del tramo estás: 0 = al principio, 1 = al final, 0.5 = a la mitad.

      
Canal
Cada número de un color: alpha (transparencia), rojo, verde y azul.

      
ARGB
Los 4 canales juntos en un solo número (int).

      
Hilo
Un trabajador independiente. Aquí hay dos.

      
Daemon
Un hilo que se cierra solo al terminar el programa.

      
Interfaz
Un contrato: dice qué métodos hay que tener, no cómo se hacen.

      
DTO
Una clase que solo guarda datos (ColorTargetDTO).

      
MVP
Modelo - Vista - Presenter. Modelo y vista no se conocen: hablan por el Presenter.
